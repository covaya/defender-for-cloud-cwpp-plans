## 使うときの注意

- **Microsoft の公式資料ではありません。** 個人が公式ページを調べてまとめたものです。
- **内容は 2026-11-19 時点です。** プラン、提供状況、価格はその後に変わっている可能性があります。
- **価格は Japan East（東日本）リージョンの参考値です。** 2026-11-20 に公式の価格ページで読み取った月額で、USD と JPY を載せています。JPY は為替レートによる換算で月ごとに変わり、契約によっても変わります。見積もりには公式の価格ページの値を使ってください。
- **人による照合を前提にしています。** 各行に脚注 `(*n)` で公式ページの URL を付けています。原文版の語句は公式ページの表現そのままなので、コピーしてページ内検索すれば該当箇所を確かめられます。
- **翻訳は独自の訳です。** Microsoft の日本語版ページの表現ではありません。
